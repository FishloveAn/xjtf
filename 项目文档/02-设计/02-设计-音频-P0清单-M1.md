## 1. 事件 → 文件映射表（工程照此接线）

> 目标文件名已按音频方向 §4.4 命名规范定死：`sfx_{类别}_{名称}_{变体号}.wav`，全部落在 `res://assets/audio/sfx/`，总线统一走 **SFX**（默认 0 dB）。
> 变体 = 同事件多文件随机播放（`pitch_scale` 再 ±5%），**MVP 每个事件至少 1 个文件即可接线，3 变体为建议补齐量**。

| 事件名 | 触发时机 | 目标文件（res://assets/audio/sfx/） | 变体 | 音量建议 | 3D/衰减 | 同发优先级 |
|---|---|---|---|---|---|---|
| `pistol_fire` | 客户端开火**立即**（本地视觉层） | `sfx_weapon_pistol_fire_01~03.wav` | 3 | 0 dB 基准 | 3D，挂玩家，`max_distance` 40m，`unit_size` 1.0 | 高（枪声池 8-16） |
| `shotgun_fire` | 客户端开火**立即**（本地视觉层） | `sfx_weapon_shotgun_fire_01~03.wav` | 3 | +2 dB（比手枪更重更低频） | 3D，挂玩家，同上 | 高（枪声池共用） |
| `zombie_hurt` | **服务器受击广播后**（不本地猜） | `sfx_zombie_hurt_01~03.wav` | 3 | -3 dB | 3D，挂丧尸实体，`max_distance` 30m | 中（打击声池 8-16 共用） |
| `zombie_died` | **服务器死亡广播后**（S6 `zombie_died`） | `sfx_zombie_died_01~03.wav` | 3 | -2 dB（含倒地撞击层） | 3D，挂丧尸实体，`max_distance` 40m | 中（打击声池共用） |
| `player_hurt` | **服务器扣血广播后**（S1 `apply_damage`） | `sfx_player_hurt_01~02.wav` | 2 | -4 dB（短促闷响，不盖枪声） | 2D 局部（HUD 层，非世界声） | 中 |
| `hit_confirm` | **服务器命中广播后**（S6 `hit_confirmed`） | `sfx_hit_confirm_01~03.wav` | 3 | -6 dB（短促"噗/啪"，替代 UI 提示） | 3D，挂命中点或玩家，`max_distance` 20m | 中（可被枪声让位） |

**限流与让位**：同帧同事件最多 4 个实例（打击声池内循环复用）；`hit_confirm`/`zombie_hurt` 可被枪声抢占（SFX 总线内先到先得 + Master Limiter 兜底），MVP 不做侧链压缩，M2 再补。

**可增删说明**：
- 若 S4 霰弹降级跳过 → `shotgun_fire` 事件保留但不接线（清单不删，M2 直接用）。
- 空仓/换弹、丧尸嘶吼、尸潮警报 = **P1，M1 不做**（音频方向 §5 扩展期）。
- 玩家受击建议**只播给自己**（受击闷响是"体感"声，队友不需要），工程侧 `player_hurt` 只在本端播。

## 2. 素材来源方案（全部 CC0 / 免费可商用，本项目零预算）

### 2.1 主选：Kenney.nl（全套 CC0，无需署名、可商用可改）——第一选择

| 包名 | 下载地址 | 包内文件（命名规律） | 对应事件 |
|---|---|---|---|
| **Impact Sounds**（碰撞/打击音） | `https://kenney.nl/assets/impact-sounds` | `impactFlesh_*.ogg`（血肉闷击）→ 受击/命中 | `zombie_hurt`、`hit_confirm` |
| | | `impactMetal_*.ogg` / `impactPlate_*.ogg`（金属重击）→ 枪声打击层、玩家受击 | `pistol_fire`（打击层）、`player_hurt` |
| **Interface Sounds**（界面/确认音） | `https://kenney.nl/assets/interface-sounds` | `confirmation_*.ogg` / `notification_*.ogg`（短促确认"咔"） | `hit_confirm`（备选） |
| **RPG Audio**（含武器/爆炸类，可选） | `https://kenney.nl/assets/rpg-audio` | 内附 fire/爆炸/重击类 | `shotgun_fire`（候选） |

> 说明：Kenney 包内为 `.ogg`（44.1kHz），Godot 直接可用；短音效按方向 §4.3 建议转 `.wav`（Audacity 导出或 Godot 导入后另存），**MVP 直接 `.ogg` 也能跑**，性能瓶颈在同发数不在格式（方向 §4.3 结论）。

### 2.2 枪声补充：freesound.org（CC0 过滤）——写实枪声 Kenney 偏弱，按需补

- 搜索词：`pistol shot` / `gunshot close` / `shotgun blast`（单个词即可，freesound 命中率高）
- **必须**：搜索结果左侧 Filters → License → 勾选 **CC0**（绝不用 CC-BY-NC / CC-BY-ND，见方向 §3.2 禁用清单）
- 下载后按 §1 目标文件名改名入库（短促裁剪 0.3-0.8s + 响度归一化）
- **降级方案（不跑 freesound 也能过 C7）**：手枪 = `impactMetal` 短击做打击层；霰弹 = `impactMetal` 重击 + 低音层（Godot `pitch_scale` 降到 0.7 加厚重感）——写实度弱、节奏稳定，标注打磨期替换。

### 2.3 入库可执行步骤（照做即可）

1. 下载 Kenney **Impact Sounds** + **Interface Sounds**（CC0，无需署名但**仍记账**）。
2. 解压，把所需文件复制到 `assets/audio/sfx/`，**按 §1 映射表重命名**（如 `impactFlesh_001.ogg` → `sfx_zombie_hurt_01.wav`）。
3. 响度归一化：目标 **-18 ~ -12 LUFS**（方向 §1）。工具：Audacity（免费）→ 效果 → 响度标准化 → 目标 -15 LUFS。
4. 枪声如需 freesound 素材：搜索 → 过滤 CC0 → 下载 → 裁剪 → 归一化 → 入库。
5. **当日记账**：写 `CREDITS/audio-sources.md`（素材名 / 作者 / 来源链接 / 许可）——总纲 §7 风险 7 纪律，下载即记账。
6. 工程侧 S7 接线：`project.godot` 建 Audio Bus（Master/SFX/Music/Ambient/UI + Master 挂 Limiter）+ `scripts/audio/sfx_pool.gd` 播放器池，事件照 §1 表触发。

## 3. 接线备注（给工程的一句确认）

- **本地立即播放（视觉层，不开服务器）**：`pistol_fire`、`shotgun_fire`——S3 已有"开火即播本地枪声/枪口火花"设计，命中与否都响，保证开枪手感零延迟。
- **服务器事件驱动（收到广播后才播，不本地猜）**：`zombie_hurt`、`zombie_died`（S6 广播）、`player_hurt`（S1 `apply_damage` 广播）、`hit_confirm`（S6 `hit_confirmed` 广播）——严格走 S6 纪律"客户端收到服务器广播后才播表现"；LAN 延迟 <10ms，听觉无感。
- **播放器池**：`sfx_pool.gd` 预建 8-16 个 `AudioStreamPlayer3D` 循环复用（枪声池 + 打击声池分离），**不每枪 new**；峰值同发 ≤32-48（方向 §4.5）。
- **总线/音量**：6 事件全走 SFX（0 dB）；Master 挂 Limiter 防枪声叠加爆音（方向 §4.2）。
