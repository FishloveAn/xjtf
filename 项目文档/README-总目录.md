## 与运行代码的关系

- **运行代码**（Godot 项目资源）：`project.godot`、`scenes/`、`scripts/`、`autoload/`、`data/`、`assets/`（项目根目录，不在"项目文档"内）
- **本文档体系**只存放设计与过程文档，与运行代码分离，互不影响
- 文档内引用运行代码使用 `res://` 相对路径（如 `scenes/ui/main_menu.tscn`）
