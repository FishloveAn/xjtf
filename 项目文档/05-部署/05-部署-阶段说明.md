# 阶段五 · 部署（阶段说明文档）

> 阶段序号：05 ｜ 阶段名称：部署 ｜ 所属项目：《星际土匪》（StarBandit, L4D-like）
> 本文件说明：本阶段要做什么、输入输出、负责人、验收标准。

## 1. 本阶段目标

将 Godot 项目导出为 Windows 可执行文件（.exe），供局域网联机分发。本作是局域网本地游戏，**不涉及**：云服务器部署、账号系统、商店上架（均为可选项，用户自行决定是否扩展）。

## 2. 任务清单

- [x] T5.1 Godot 导出配置（export_presets.cfg，Windows Desktop 模板）
- [x] T5.2 首次导出验证（M3-S8 完成，模板已装，headless 冒烟 exit=0）
- [x] T5.3 包体与性能核对（starbandit.exe 109MB < 600MB 目标 ✓）
- [x] T5.4 局域网分发说明（同一局域网内拷贝 exe 即可联机；防火墙放行 5555 端口）
- [x] T5.5 发布物清单：版本 0.9.0、素材署名（CREDITS/audio-sources.md + models-sources.md）

## 3. 输入 / 输出

| 类型 | 文件 |
|------|------|
| 输入 | 已完成 M3 的项目代码、`assets/` 资源 |
| 输出 | `export_presets.cfg`（项目根目录） |
| 输出 | Windows 可执行文件（build/ 目录，导出时生成） |

## 4. 负责人

| 角色 | 成员 | 职责 |
|------|------|------|
| 构建/版本 | 路远行（release-ops-lead） | 导出配置、版本号、补丁说明、素材署名 |
| 工程支持 | 程基岩（engineering-lead） | 导出报错排查 |
| 最终验证 | 严守真（quality-lead） | 导出后冒烟回归 |
| 决策 | 用户（开发者） | 确认发布范围 |

## 5. 验收标准

1. 导出的 exe 在干净的 Windows 机器上可运行（不依赖编辑器）
2. 局域网两台机器通过 exe 可建房/加房
3. 包体 < 600MB
4. 素材署名文件（CREDITS）齐全（有 CC-BY 素材时必做）
