# 冒烟测试清单（M0 项目骨架 / M1 战斗闭环）

> 用途：M0 交付后，由开发者在 Godot 4.7.x 编辑器里逐条手动验证；M1 起追加 C（单机战斗闭环）/ D（联机战斗）组，对应 M1 战斗闭环里程碑（验收标准见 `03-开发-M1任务卡.md` §2）。
> 里程碑判据（tech-plan §9）：**A/B 组全过 → 进入 M1**；**C/D 组全过 → M1 完成**（M1 任务卡 §3 质量门）。

## A. 项目能打开、单机可玩

- [ ] A1. 用 Godot 4.7.x 打开项目根目录（含 project.godot 的目录），无脚本解析错误（输出面板无红色 Error）。
- [ ] A2. 按 F5 运行，进入主菜单，标题显示"星际土匪"。
- [ ] A3. 点"创建主机"→ 进入大厅 → 点"开始游戏"→ 进入主场景（地面 + 天空 + 光线）。
- [ ] A4. 玩家可 WASD 移动、Space 跳跃、鼠标转视角（鼠标被捕获）。
  - 操作：WASD 移动 / Space 跳跃 / 移动鼠标转视角；移动时系统光标不可见（鼠标已捕获）。
- [ ] A5. 按 Esc 释放鼠标；再点击窗口可重新捕获。
  - 操作：按 Esc 出现系统光标 → 点击游戏窗口 → 光标重新捕获隐藏。
- [ ] A6. 走到地面边缘会掉下去再落回？—— 不需要：地面是 40x40 大平台，走出会坠落（可选验证重力）。
- [ ] A7. 玩家角色胶囊（蓝色）出现在出生点附近。

## B. 局域网建房 / 加房（两台 Windows 机器，或同一机器开两个实例）

- [ ] B1. 机器 A：点"创建主机"（端口 5555）→ 大厅显示"在线玩家：1 / 8"，有"开始游戏"按钮。
- [ ] B2. 机器 B：填 A 的局域网 IP + 端口 5555 → 点"加入游戏"→ 进入大厅，显示"等待主机开始游戏"。
- [ ] B3. A 的大厅玩家列表变成 2 / 8，出现 peer id 2。
- [ ] B4. A 点"开始游戏"，A、B 同时进入主场景。
- [ ] B5. A 与 B 能互相看到对方的蓝色胶囊，且看到对方移动/转向（MultiplayerSynchronizer 同步）。
- [ ] B6. B 控制自己的角色移动，A 端看到 B 平滑移动（20Hz 同步 + 插值）。
- [ ] B7. B 直接关掉窗口（断线），A 端该玩家胶囊消失，A 不崩溃。
- [ ] B8. A 直接关掉窗口（主机退出），B 端自动回到主菜单，不崩溃。
- [ ] B9. 端口被占用时（如再开一个 5555 主机），提示"创建主机失败"。

## C. 单机战斗闭环（M1）

- [ ] C1. 玩家出生 100 HP，HUD 血条显示；受击扣血下降；血量归零进入倒地。操作：运行主场景 → 确认 HUD 血条为 100 → 触发调试扣血（-20）→ 血条降至 80 → 连续扣至 0 → 进入倒地（移动禁用 + 倒地标识）。
- [ ] C2. 手枪开火/弹药/换弹：鼠标左键开火弹匣 -1，HUD 显示弹药（9 / 12）；打空自动换弹或按 R 手动换弹；连点受射速限制（5.0 发/秒）。操作：拿起手枪 → 连点左键 → 弹药递减 → 打空自动换弹 → 中途按 R 手动换弹 → 换弹期间不可射击。
- [ ] C3. 手枪击杀丧尸（血雾/倒地）：命中点出血雾 + 受击音效；丧尸倒地/淡出后从场景移除；连杀 10 只无节点泄漏。操作：对丧尸开火命中 → 观察血雾/音效 → 打满伤害击杀 → 丧尸倒地消失 → 连杀 10 只 → 检查 Zombies 容器子节点数回落。
- [ ] C4. 丧尸追踪 + 近战攻击扣血：丧尸向玩家直线移动；进入攻击距离近战命中扣血（走 damageable）；攻击有冷却；玩家跑出追击范围后丧尸停止追击回 Idle。操作：生成丧尸 → 观察直线追踪 → 站桩让丧尸近身 → 前摇后玩家掉血（HUD 下降）→ 拉开距离 → 丧尸停止追击。
  - 加压可选：打开 `tests/scenes/test_zombie_ai.tscn` 刷 10 只，主场景保持 60 FPS（M1 只做 ≤30 只初验）。
- [ ] C5. 倒地 → 救援 → 复活：HP=0 进入倒地（移动禁用、视角保留、有倒地标识）；按 E 触发救援进度 3 秒 → 复活 HP 恢复至 50；倒地期间再次受击 → 死亡（淡出/黑屏提示）。操作：血量扣至 0 → 确认倒地状态 → 按 E 救援 → 进度条走完 → 复活回 50 HP；再倒地后受击 → 死亡。
  - 说明：单机无队友实体时，救援交互可先用调试手段刷出可救援对象验证，或与 D3 双人救援合并验证。
- [ ] C6. 霰弹枪散射击杀/切枪：一次开火 8 颗散射弹丸；近身（≤10m）可一发击杀普通丧尸；数字键 1/2 切换手枪/霰弹，弹药独立。操作：按 2 切霰弹 → 确认 HUD 弹药 → 近身 ≤10m 对丧尸开火 → 一发散射击杀 → 按 1 切回手枪 → 确认弹药独立计数。
- [ ] C7. 反馈链每环节有声：开枪 → 击中 → 丧尸倒地 每环节有声（手枪/霰弹枪声、命中音、丧尸受击/倒地音、玩家受击音）。操作：开枪听枪声 → 命中丧尸听命中/受击音 → 击杀听倒地音 → 被丧尸攻击听玩家受击音。

## D. 联机战斗（M1）

- [ ] D1. 双人互见开枪：A 端开枪，B 端看到 A 的枪口火花/枪声/命中表现；B 开枪，A 端同样可见。操作：A、B 双人进主场景 → A 开火 → B 端观察枪口/枪声 → B 开火 → A 端可见。
- [ ] D2. 服务器复判伤害一致：A 开枪击杀丧尸，B 端看到同一只丧尸同步掉血/死亡；丧尸攻击 A 掉血，B 端 HUD 同步看到 A 掉血，两端结算一致。操作：A 打丧尸 → B 端观察丧尸血条/死亡同步 → 丧尸攻击 A → B 端观察 A 掉血 → 两端对比无偏差。
- [ ] D3. 双人救援：A 血量归零倒地 → B 走到 A 身边按 E → 救援进度 3 秒 → A 复活（HP 50），两端可见状态一致。操作：A 被丧尸击杀倒地 → B 靠近按 E → 观察救援进度条 → A 复活 → A/B 两端确认状态同步。
- [ ] D4. 双人 30 分钟联机稳定性：A/B 双人持续游玩 30 分钟（移动/射击/击杀丧尸/救援循环），无崩溃、无断线、无红色 Error，主机保持可玩帧率。操作：双人进场景 → 正常游玩循环 30 分钟 → 观察 A/B 是否崩溃/断线 → 输出面板无红色 Error。

## E. 已知 M0 边界（不修，记录）

- 远端玩家头部俯仰（pitch）已同步，但无插值平滑，微抖可接受。
- 不做客户端预测/回滚（tech-plan §4.3 后续里程碑再做宽松校验）。
- 不做主机迁移；主机退出即回主菜单（tech-plan §4.5）。
- 单机（不开网络）也能直接玩：主场景会生成一个本地玩家。

## 备注

- 同机双开验证：先把主菜单里 IP 默认值改成 `127.0.0.1`，机器 A 建房后，机器 B 实例填 `127.0.0.1:5555` 即可。
- 防火墙：Windows 首次建房可能弹防火墙授权，选"允许"（专用网络）。
