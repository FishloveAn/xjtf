# ADR-007：武器 = hitscan + 数据驱动（JSON）

- 状态：定案
- 日期：2026-08-04

## 背景

Low Poly 局域网 FPS，追求实现简单与数值可调。

## 决策

- 命中检测用 **hitscan（intersect_ray）**，不用投射物（物理子弹无必要）。
- 武器参数（伤害/射速/弹匣/换弹/散射/射程）放 `data/weapons.json`，脚本只读 + 应用。
- 射击流程：客户端本地视觉 → 客户端 raycast 预览 → 服务器复判 → 广播命中。

## 结论

数据驱动让数值平衡改 JSON 不碰代码；hitscan 实现量最小、手感直接。
