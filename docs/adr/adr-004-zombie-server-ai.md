# ADR-004：丧尸 AI 只在服务器跑，客户端快照 + 插值

- 状态：定案
- 日期：2026-08-04

## 背景

同屏 100 只丧尸，AI 若客户端也跑会双倍消耗且易状态不一致。

## 决策

- 丧尸 AI（寻路/攻击/状态机）**只在服务器执行**，客户端纯显示。
- 位置/朝向/状态经 MultiplayerSynchronizer（MVP）或自定义快照（优化期）同步，客户端插值平滑。
- 丧尸生成/死亡由服务器 Spawner/快照驱动，客户端绝不直接生成网络丧尸。

## 结论

单一真相源 + 客户端纯渲染，避免状态分叉；配合分帧 AI 预算与对象池支撑 100 只。
