# ADR-006：普通丧尸动画（剥骨静态 + 代码摆动；MultiMesh 延后）

- 状态：定案（2026-08-06 修订）
- 日期：2026-08-04（初定）；2026-08-06（修订）

## 背景

初版决策：普通丧尸 = MultiMesh + 顶点着色器动画，特感 = 骨骼。后经 M3-S4/S8 实测修正。

## 决策（修订后）

- 普通丧尸：**带骨骼免费模型剥骨 → 无骨骼静态 .glb + 代码 transform 摆动**（bob/前倾/倾斜 + 相位随机），不播骨骼动画、不烘焙顶点色掩码。
- 特感：带骨骼 + AnimationPlayer（≤5 只，无性能压力）。
- **MultiMesh 延后**：M3-S4 实测 100 只独立实例 CPU 6.9ms 贴地板，简化方案达标，MultiMesh 未来兼容（模型已无骨骼）。

## 结论

免费包无顶点色掩码使顶点 shader 动画不可执行；剥骨静态 + 代码摆动与 MultiMesh 零成本兼容，观感在 Low Poly 尸潮密度下足够。详见 `docs/项目文档/02-设计/02-设计-美术-替换清单-M3.md` §2.1。
