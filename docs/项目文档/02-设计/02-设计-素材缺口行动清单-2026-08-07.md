### 1.2 模型来源（按优先级）

**来源 A：Quaternius（CC0，首选）**
- 包：**Ultimate Monsters**（https://quaternius.com/packs/ultimatemonsters.html）
  - ✅ 50 个**带动画**怪物，格式 FBX/OBJ/Blend/glTF，**CC0**，纹理齐全
  - ⚠️ **免费版无动画哥布林**（动画哥布林是 Patreon 专属）——包内挑**瘦/壮人形怪**（zombie/undead/skeleton 类）改色给 R1/R2 用
- 包：**LowPoly Animated Monsters**（https://quaternius.com/packs/lowpolyanimatedmonsters.html 或 itch 页）
  - ✅ 带 punch/attack/jump/walk 动画的怪物包，CC0
  - ⚠️ 同样：免费版哥布林缺失（Patreon 专属）
- **结论**：Quaternius 免费包可满足**普通丧尸（R1/R2）**，**哥布林特感（R4/R5/G3/G4）大概率要另找**。

**来源 B：Poly Pizza（CC0 筛选）**
- 搜 `low poly goblin` / `low poly orc` / `low poly imp`（https://poly.pizza/search/goblin）
- **只取 CC0**（CC-BY 需署名，默认不取）；下载 `.glb` 直接可用
- 预期可找到：哥布林战士/法师/小体型怪物——挑尖耳 + 弓背 + 獠牙剪影的
- 若 Poly Pizza 无带动画的 → 取静态模型，动画按替换清单 §2.1 方案 B（剥骨 + 代码 transform 摆动，仅普通丧尸）或 §2.3（特感挂 AnimationPlayer，动画 6 槽）

**来源 C：AI 生成 + Blender 清洗（兜底）**
- 概念图已出（`goblin_*.png`），可直接**图生 3D**（Meshy/Tripo 或工具内置生成）
- 出 .glb 后按替换清单附录 B 清洗：Decimate 减面（特感 ≤4000 tris）→ Recalculate Outside → Merge by Distance → 比例校准（底部 Y=0，高 1.8m 参照，门 2.4m）→ 面朝 -Z → 导出 +Y Up
- 成本：每模型 10-30 分钟，只用于免费包找不到的缺口

### 1.3 执行步骤（每个模型 10-30 分钟）

1. 下载 → 解压到 **`C:/Users/668/Documents/Fish/_tmp_art_downloads/`**（**项目外**临时目录，⚠️ 2026-08-07 实测教训：放在项目根目录内会被 Godot 扫描导入，坏文件直接拖崩编辑器）
2. 挑选：R1/R2 从 Ultimate Monsters 挑瘦/壮人形怪；哥布林从 Poly Pizza 挑
3. **⚠️ 入库前必查来源**：Poly Pizza 上 Quaternius 模型的 glb 是 **FBX2glTF v0.9.7 老工具导出**（实测 `Orc Enemy` 让 Godot 4.7.1 加载即段错误崩溃！）。**下载后先跑 `tools/check_model_spec.gd 单文件` 验证**，崩溃 = 弃用换下一个；正常项目模型是 **trimesh 导出**（纯几何，无动画无骨骼）
4. Blender 清洗（见替换清单附录 B 速查）：
   - **普通丧尸**：删 Armature（剥骨）→ 导出无骨骼 .glb（走代码摆动动画）
   - **哥布林特感**：保留骨骼 → 动画槽统一 `idle/walk/attack/hurt/death`（spawn 用淡入）
   - 全部：减面达标、修法线、清重复点、比例校准、面朝 -Z
5. 导入 `assets/models/characters/` → 命名 `char_zombie_common_01.glb` 等
6. Godot 材质统一：StandardMaterial3D + Flat Shading + `albedo_color` 按规格
   - 丧尸瘦 `#8A7A66` / 壮 `#7A8A66`｜哥布林冲撞 `#FF7A2F`｜喷吐 `#7A8A66偏黄`+脓包 emissive｜跳跃 `#3DDC84`｜自爆 `#8A3A2E`+腹部 emissive
6. **记账**：`CREDITS/models-sources.md` 逐条登记（素材名/作者/链接/许可/用途），下载即登记
