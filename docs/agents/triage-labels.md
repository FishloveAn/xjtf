# Issue 流程标签

| 流程角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估和分类 |
| `needs-info` | `needs-info` | 信息不足，等待报告者补充 |
| `ready-for-agent` | `ready-for-agent` | 范围与验收标准完整，可由开发代理独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工判断、操作或实现 |
| `wontfix` | `wontfix` | 已决定不处理 |

同一 Issue 应只保留最符合当前状态的流程标签；`bug`、`enhancement`、`documentation` 等类型标签可与流程标签并存。
